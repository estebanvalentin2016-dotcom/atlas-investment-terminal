# v0.10 Opportunity Radar — first discovery increment

ATLAS opens on an automatic recent 8-K review queue. It calls the existing SEC endpoint sequentially for eight predefined liquid-company tickers (CRWD, NVDA, MSFT, AMZN, META, GOOGL, PLTR, AVGO) and shows source-linked, timezone-aware recent 2.02 earnings / 1.01 material agreement disclosures from the prior fourteen days. Earnings come first only as a **research-review priority**, never a bullishness score or profit forecast. Failed sources are surfaced, not replaced with fake data. The queue auto-populates when the screen opens and can be manually refreshed.

**Not yet included:** validated positive fundamentals, extracted guidance surprises, source-matched initial public news, current market quotes/remaining-upside estimates, overnight venue validation, multi-market expansion, background scanning, or automatic trading. The queue currently surfaces **leads**, not verified opportunities. Those are the next increments needed to satisfy the actual research objective.

This branch starts from the previously tested v0.9 branch while v0.9 remains unmerged. `npm.cmd run build` and `npm.cmd run test` must be run locally before any merge. The existing demo pages remain fictional.

## Broad discovery increment
The Opportunity Radar now fetches SEC market-wide daily master index files (seven calendar-day dates, with absent holiday/weekend indexes skipped), using `SEC_USER_AGENT` and SEC's company ticker directory to resolve symbols. Recent 8-K and 8-K/A links are returned, with source failures and partial coverage exposed and a ten-minute response cache. Up to 40 newest links are presented for review. This is much wider than the previous eight-ticker poll but **not full opportunity discovery**: SEC master indexes do not supply Item 2.02/1.01, reliable first-public timestamps, bullishness, forecast upside, or stock liquidity. Unlisted companies are excluded. The prior 8-ticker parser still exists for regression tests and other uses. Event analysis and positive-catalyst classification are next.

## Full discovery queue increment (October 15, 2026)
Live source inspection established that SEC daily master indexes use compact `YYYYMMDD` filing dates and include hundreds of ticker-matched 8-K records. The parser now converts valid compact dates to ISO without guessing invalid dates, and preserves the distinct index date. The discovery endpoint returns up to 1,200 unique leads (formerly capped at 40). The UI paginates 20 per page, supports ticker/company search and index-date filtering, and optionally shows only one filing per ticker. Raw filing counts are explicitly not an opportunity or bullishness score. Source coverage remains partial for HTTP 403 days, and the local scanner does not poll in the background.

**Next intended step:** evidence-based company event classification from authoritative disclosure contents (not just 8-K presence), followed by observed price-reaction and remaining-upside research, venue/liquidity checks, and transparent rejection reasons. Do not label an event bullish or actionable from an SEC form code alone.
